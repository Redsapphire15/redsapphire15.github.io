# Kavin Arvinth Ravichandran — Academic Website

A minimal, research-oriented personal website inspired by the visual conventions of academic lab and researcher pages.

## Deploy with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site at https://redsapphire15.github.io.

## Personalise before sharing

- Replace the GitHub avatar in `index.html` with a professional portrait if desired.
- Add a real CV PDF at `cv.pdf`.
- Replace placeholder project links with public repositories, papers, and demos when available.
- Add project photographs, videos, and figures as they become available.
- Replace the LinkedIn and Google Scholar placeholder destinations with the exact profile URLs.

## Updating

Edit `index.html` for content and `stylesheet.css` for styling. Push changes to `main`; GitHub Pages will rebuild the site automatically.
